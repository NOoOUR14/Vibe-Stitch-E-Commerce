## 🚀 How to Run Locally

### Backend Setup
1. `cd backend`
2. `npm install`
3. `npm start` (Runs on http://localhost:5000)

### Frontend & Dashboard Setup
*(Repeat these steps for both the customer app and dashboard if they are separate)*
1. `cd ecommerceApp`
2. `npm install`
3. `ng serve` (Runs on http://localhost:4200)

---

## 🛠️ Technologies Used

### Frontend & Dashboard
* **Framework:** Angular
* **Styling:** Bootstrap / Tailwind / CSS
* **State Management:** Local Storage

### Backend
* **Server:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JSON Web Tokens (JWT)
* **File Uploads:** Multer / Cloudinary
